# SAEDIndex Desktop Implementation Plan

> **For agentic workers:** Execute inline in this shared project. Follow
> test-driven-development and verification-before-completion for every change.

**Goal:** Deliver a working Chinese diffraction-indexing desktop app.

**Architecture:** Session owns numeric state; rendering owns presentation and figure
export; canvas handles image interaction; window coordinates files and controls.
Long analysis uses a QThread; GUI mutation remains on the main thread.

**Tech Stack:** Installed PySide6, numpy, scipy, Pillow, Python unittest.
