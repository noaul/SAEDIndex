# SAEDIndex 衍射标定工作台

## 启动

双击本目录 `Start-SAEDIndex.cmd`。

也可在 PowerShell 运行：

```powershell
cd D:\科研论文\SAEDIndex
.\venv\Scripts\python.exe main.py
```

支持将图片或 `.saed.json` 项目路径作为命令行参数。
当前启动环境配置于本机；移动到其他电脑需要重新安装依赖，并提供字体。

## 打包版

- 免安装版：`dist\SAEDIndex\SAEDIndex.exe`，整个 `dist\SAEDIndex` 文件夹需一起拷贝；
  压缩包为 `dist\SAEDIndex-win64.zip`，解压后运行其中的 exe，目标电脑无需 Python。
- 改代码后重新打包：`powershell -ExecutionPolicy Bypass -File .\Build-SAEDIndex.ps1`。
  脚本会精简 PATH，避免把其他软件的旧 ICU 等 DLL 打进包导致 QtCore 加载失败。
- 默认 CIF 仍从 `D:\cif` 读取；其他电脑没有该目录时用“导入 CIF”手动添加。

## 工作流程

### 工作台与亮点筛选

- 白底界面，左侧按“定标 / 识别 / 显示”分页，同类设置以小圆角工具分组显示；
  右侧保留候选、矢量、斑点、诊断以及模拟、标注、出图标尺。
- 画布上方“斑点圈”只控制检测点圆圈，不隐藏中心、CIF 模拟框或晶面标注。
  顶部眼睛按钮仍是全部辅助标记的总开关。显示页可单独控制透射中心。
- 识别页可调亮点阈值、最小/最大直径、峰间隔及平滑尺度。
  直径指原图中局部背景扣除后的半峰高连通面积等效直径，单位是图像像素，
  不是晶面间距，也不是圆圈显示半径。默认两端“不限”，保持旧版检测结果。
- 提高最小直径可筛去细小亮点，提高亮点阈值可筛去弱点；点击“重新识别斑点”
  才会重做检测、中心、分组和 CIF 索引。真实弱反射也可能被筛掉，请结合模拟核对。
  点选斑点可查看其半峰高直径；旧项目未记录尺寸的点不会虚构直径。
- 重新识别保持科学定标和出图覆盖区域，支持撤销/重做以恢复斑点、参数、组别和
  确认状态。新检测结果需重新确认。存在未应用的标尺草稿时，须先应用或恢复。
- 标注样式支持“化学式数字下标”，例如 NbNi3 显示为 NbNi₃，晶面指数仍使用
  原有负号上划线。此选项只影响显示/出图，不修改 CIF 或原始名称。
- 新增检测参数与显示选项随项目保存，兼容缺少这些字段的旧项目。

### HRTEM：FFT 标定与 IFFT 重构

- 工具栏“导入 HRTEM”(Ctrl+Shift+O) 读取 DM3/DM4、TIFF、PNG、JPG 高分辨像。
  画布上方出现“原图 / FFT / IFFT / 对照”视图切换；衍射图流程不受影响。
- 实空间定标与衍射定标分开：定标页单位变为 nm / Å，标尺端点画在原图上。
  优先使用 DM 各轴实空间比例；两轴像素不等时禁止 FFT 绝对标定；DM 与图中 nm 标尺
  相差 >3% 时两者都不自动采用。倒易标尺 (1/nm) 不会被当作实空间比例。
  普通图片无可靠比例时仍可看 FFT，但不做 CIF 索引。
- FFT 只取正方形 ROI（默认避开图中标尺）：减均值、Hann 窗、fft2 + fftshift。
  中心固定为零频，不做 SAED 透射斑搜索。1 FFT 像素 = 1/(N·倍率·nm/px) 1/nm。
  “FFT 倍率”自动或 1/2/4/8×，用 chirp-z 在零频附近加密采样（等效补零），
  不改变倒易标定。对数谱只用于显示，峰位在数值幅值谱上做亚像素定位，并成对给出 Friedel 点。
- FFT 索引沿用 CIF 候选、等价标法、矢量闭合与手动 hkl，但只按几何（长度比、
  共同尺度、夹角、消光、晶带先验）评分，不使用 SAED 强度及“未见预测峰”罚分。
- IFFT 由保留的复数谱（未加窗）重建，不读取导出的 FFT 灰度图。
  可点选 FFT 斑点（自动含对称点）、只用当前组或全部斑点，并调掩膜半径与余弦软边。
  “对照”视图左为 ROI 原图、右为 IFFT。ROI、倍率、选点、掩膜修改均可撤销。
- 导出按当前视图：FFT 图带 1/nm 标尺与晶面/晶带轴标注；原图、IFFT、对照图带
  nm 标尺（显示页“出图标尺”可设数值）。导出图不含 ROI 框、选点圈等编辑标记。
- 项目文件升级为 version 2（仍可打开 version 1），保存源图 SHA256、ROI、实空间比例、
  FFT 倍率、IFFT 参数及处理版本；打开时从源图重新计算 FFT/IFFT，不保存大数组。
- 限制：FFT 周期可能来自莫尔条纹、半周期衬度或样品漂移；IFFT 是所选频率的
  滤波结果，不产生新信息。未实现 GPA 应变分析。当前仅用合成晶格图验证，
  尚未用带可靠比例的真实 HRTEM 样品做人工复核。

### 标定与导出

1. 导入 JPG/PNG/TIF/BMP/DM3/DM4。程序自动读取倒易标尺，检测斑点、估算中心，
   拟合最多三组晶格，并与已勾选的 CIF 比较。
2. 标定优先读取同尺寸同名 DM 的 `1/nm` 元数据，同时用图中标尺核对；
   没有可用 DM 时，检测标尺并识别数字。低置信度结果不自动用于索引。
   普通 `nm` 实空间标尺不会被当作 `1/nm`。
3. 在左侧“科学定标”核对自动识别的数字、单位、有效像素长度及原标尺截图。
   可点选或拖动原标尺端点，也可输入端点坐标、有效长度、数值和倒易单位。
   点击“应用标尺定标”才改变科学计算比例；未应用的修改会阻止确认和出图。
   旁边的恢复按钮放弃待应用修改。也可直接输入 `px/(1/nm)` 并应用。
4. 选斑点组，比较“CIF 候选”“矢量对比”“全部斑点”。候选评分越低越优，
   不是概率；`Δg` 为 `|g|实测/|g|CIF − 1`，`Δd` 为 `d实测/dCIF − 1`。
5. 勾选 CIF 位置叠加，与实测图对照。默认严格使用标尺比例。
   “允许比例拟合”只改变模拟大小，不改变测量值或标定；用来辅助查看共同尺度偏差，
   不应据此直接认定物相。
6. 核对后“确认当前候选”。修改标定、中心、斑点或候选会取消原确认。
7. 导出 PNG/TIFF 标定图，或 CSV 测量数据。保存项目可保留全部编辑状态。

默认载入 `D:\cif` 中的 Ni、NbNi3、达尔塔NbNi3、NbC；可增删 CIF 或取消勾选。
额外的 CIF 导入后会重新搜索候选。

## 手工修正

- 工具图标悬停显示名称：平移、数据检查、设定中心、补点、删点、移点、
  双斑点建组、点击删除组、移标注、定标尺端点、出图覆盖区域。
- 滚轮围绕鼠标缩放；平移工具拖动图片。补点会尝试局部质心定位。
- 双斑点建组需要先有中心，依次选两个不共线斑点。它们分别作为该组 g1/g2。
- 斑点组右侧的加号同样进入建组模式；垃圾桶删除当前组，不删除原始斑点。
  左侧“点击删除组”可在图上点击该组斑点或平行四边形；组重合时优先删除当前组。
  自动分组是候选，误分成两组时可删除多余组；也可将识别条件中的组数上限设为 1。
- 默认平移模式下，直接拖动晶面指数或晶带轴文字即可调整位置；
  空白处拖动平移图片，中键也可平移。“移动标注”模式同样可拖动文字。
- 等价标法只改变对称等价的指数标法。指定 hkl 输入三指数，形式为
  `1 -1 0; 0 0 2`；当前所选候选决定所使用的 CIF。
- 缺少第三个实测斑点时，不把构造出的平行四边形当作独立矢量闭合证据；
  对比表标为“未检出”，CSV 实测列留空。
- 顶部工具栏的撤销 (Ctrl+Z) / 重做 (Ctrl+Y) 覆盖：移动、补充、删除斑点，
  设定中心，建组、删组，拖动标注，应用标尺或像素比例。撤销会同时恢复
  当时的候选与确认状态。标尺端点有未应用的修改时，第一次撤销先放弃该草稿。
  打开新图、打开项目或增删/启停 CIF 后历史清空；重新识别现已支持撤销。
- 眼睛按钮 (H) 显示 / 隐藏斑点圈、中心十字、定标端点和模拟框，只影响屏幕显示，
  晶面指数和晶带轴标注保留；选择斑点或标尺类工具时自动重新显示。

## 可靠性修订（2026-10-29）

- 自动分组增加重复位移候选、多候选稳健重拟合，并在选择候选时检查网格占用率。
  后续组至少需要 6 个新增斑点；少于 10 个新增点的稀疏候选还需要两对中心对称点。
  证据不足时保留检测点，仍可手工建组。组数上限仍是上限，不是必须找到的组数。
- 新增“诊断”页：支持点、新增/共享点、检测点覆盖、节点占用估计、RMS、最大残差、
  独立实测闭合和评分分项。点选表格行定位原图斑点；“本组外”不等于错误斑点。
- CIF 模拟中的“匹配状态与残差”使用固定科学比例：青色为匹配、橙色为偏差、
  灰色为未检出，连线显示模拟点与对应实测点的偏离。开启时暂停自由比例显示。
  这些检查图层服从标记显隐，不进入论文导出。
- 同尺寸 DM 与高置信度图中标尺比例相差超过 3% 时暂停自动定标，展示双方数值，
  由人工核对并应用；应用后可撤销回冲突状态。低置信度 OCR 不直接否定可信元数据。
- “应用 CIF 辅助比例”需显式确认，记录所用候选、重新索引并清除确认，支持撤销。
  角度或长度比超差时不可用共同尺度消除冲突。来自 CIF 的比例不能作为同一物相的独立证据。
- CSV 增加原始比例证据、诊断及评分分项。参考斑点未检出时不再导出推算夹角为实测值。
  无绝对标尺时仍可检查像素单位下的晶格残差和实测闭合。

验证记录见 `verification/reliability-validation.md`。16 个固定合成样本加 30 个独立种子
压力样本的组数判断，旧版为 30/46，新版为 46/46；该结果不代表真实图的物相识别准确率。
压力样本中有一组斑点召回率为 84.4%，组数正确不代表全部斑点归属正确。
8 张按拍摄系列区分的实测图保留前后对照，组数和物相真值尚未人工复核。
FFT、两相取向关系和倾转辅助属于后续阶段，本版尚未加入。

## 出图

- 负指数用真实绘制的上划线，不依赖字体组合字符。
- 支持多组不同颜色、移动标注、选择平行四边形方向、物相前缀。
- 右下分为“CIF 模拟”“标注样式”“出图标尺”三个页签。
  标注样式可调整字高、加粗、标定线宽；这些参数及拖动位置随项目保存。
- 模拟位置使用带黑色描边的青色框及中心十字，大小按屏幕像素保持，
  支持调节大小和不透明度；开启叠加会退出论文出图预览。
- 科学核对阶段始终保留原图标尺。勾选“论文出图预览”后才显示替换效果，
  同时隐藏检测圈、中心标记、定标端点及模拟框，与导出内容一致。
- 出图标尺的数值、字高、粗细和覆盖区域独立设置，不改变科学定标、
  斑点检测排除区域或原始图片。
- 替换标尺长度严格等于 `标尺数值 × px/(1/nm)`，白色实心线、Times New Roman 粗体。
  覆盖区域应由用户检查；不适合覆盖的情况可取消替换或重新框选区域。
- 原像素分辨率导出，写入 600 dpi 元数据。不会凭空增加原图分辨率。
- 斑点检测圈及 CIF 模拟框只用于检查，不进入标定图。
- 未确认候选只能经明确提示后导出草稿。示例文件
  `verification/delta-example-draft.png` 未经材料实验人员确认，只作功能演示。
  本轮新版预览为 `verification/revision-publication-draft.png`，同样是待确认草稿。

## 验证结果与边界

2026-10-29 本机开发数据复核：155 张有可对照 DM 的衍射 JPG，
测试时复制成无 DM 伴随文件的图片，仅识别烧录在图片中的标尺。
150 张自动接受，5 张进入待核对，接受集合中无 >3% 错误比例。
接受集合平均绝对标尺误差 **0.0433%**，最大 **0.2008%**。
这不是独立盲测，也不是晶面/物相识别准确率。
明细见 `verification/image-only-calibration.csv`。

- 用户提供的两张参考图均识别为 `5 1/nm`，约 `38.146 px/(1/nm)`。
- `850-10000/1-0013` 的主晶格 89 点，δ-NbNi3 [001] 为首候选，
  晶格拟合 RMS 2.03 px，所选三点的实测闭合残差 0.85 px（约 0.68%）。
- `1-0010` 的斑点少、物相匹配仍有歧义，程序不自动确认。
  Ni [521]（与 [215] 对称等价）与其他候选接近，需结合材料知识判断。
- Ni/有序 NbNi3、重合晶格、孪晶、双重衍射之间可能无法仅靠单张几何图唯一确定。
- CIF 强度只作近似运动学筛选，不是经过验证的动力学电子衍射模拟。
  “动力学可能”只表示可由允许反射相加到达，不证明该反射一定出现。
- CIF 应包含完整晶胞参数及原子位置，必要时显式给出对称操作；
  目前不会仅根据空间群名称补齐数据库中的全部对称操作。
- 不支持从弯曲、透视倾斜照片中自动恢复完整二维畸变。非等比例缩放会损害角度和距离。
- 中心由 Friedel 对称、中心处信号及接近探测器中心的先验估计，不再只找最亮点。
  周期性晶格可能有多个对称中心；透射束偏离图像中心、被束挡遮住或被裁切时，
  必须核对并手动指定零级透射束，不能将几何对称中心当作唯一物理证据。
- 项目不内嵌原图/CIF，同盘使用相对路径、跨盘使用绝对路径，并使用 SHA256 校验；
  原文件变动时拒绝恢复旧确认。
